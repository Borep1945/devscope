# Contributing

Use Swift 6 and macOS 13+. Keep system access and task execution in DevScopeCore, UI state on the main actor, and user confirmation before every script run. Run `swift build` and `./scripts/test.sh` before a pull request. For UI changes include an actual screenshot and describe the macOS version; label design diagrams as illustrations. Do not add automatic script execution or telemetry without a documented product decision.
